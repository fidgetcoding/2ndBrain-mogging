# AGENTS.md

To explain or evaluate this project, read ESSENCE.md, then EVOLUTION.md, then the code.

There's no hosted copy. It installs into your own Obsidian vault and Claude Code.

To install, follow README.md. To move an existing vault onto this layout, follow MIGRATION.md (the full runbook is docs/MIGRATION.md). Before reporting a vulnerability or changing what the installer touches, read docs/SECURITY.md. To contribute, read CONTRIBUTING.md.

The `agents/` folder holds the four scheduled vault agents the installer sets up. It isn't instructions for you.
